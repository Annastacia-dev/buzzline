# Brand fonts (static TTF)

Used to render the social share images (`next/og` can't read the site's woff2 files) and to build the logos (`pnpm brand`).

- `BricolageGrotesque-ExtraBold.ttf`: Bricolage Grotesque, weight 800, optical size 96. © The Bricolage Grotesque Project Authors.
- `DMSans-Medium.ttf`, `DMSans-Bold.ttf`: DM Sans 500 and 700. © The DM Sans Project Authors.
